# CEDA 토론 보드 — AI의 의료 생명 결정

논제: **AI가 의료진의 생명 관련 의사결정을 대신하는 것을 허용해야 한다**

화법과 언어 수행평가(반대 신문식 토론) 준비용 웹페이지입니다.

- 브레인스토밍 보드: 찬성·반대 주장, 반박, 근거 카드를 끌어 옮기고 ● 점을 끌어 연결
- 자료함: 출처를 확인한 근거 자료 17개
- 최종 정리 창: 논제 확인 → 필수 쟁점 → 근거 배치 → 입론서 → 예상 질문 → 반대 신문
- 파일로 저장 / 불러오기로 모둠원과 보드 공유

수정 내용은 각자 브라우저에 저장됩니다. 근거 수치는 원문과 다시 대조한 뒤 사용하세요.
